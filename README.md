## 安装

Claude Code 及兼容 Agent Skills 的工具：将本仓库克隆到 skills 目录后即可通过 skill 名称 `justin-sun-perspective` 调用。

```bash

```

其他 agent 框架：将 `SKILL.md` 全文作为系统提示词或项目指令文件引入即可。
